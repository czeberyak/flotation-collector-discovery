## 1. Цель и скоуп — предельно узко, предельно чётко

**Что делаем:** виртуальный скрининг молекул-собирателей (класс:
алкилксантогенаты) для сульфидной флотации через связку
RDKit-дескрипторы + DFT-дескрипторы (Psi4) + QSPR-модель на синтетическом
(но литературно обоснованном) таргете + ранжирование расширенной
виртуальной библиотеки.

**Чего НЕ делаем (явно, чтобы не расползалось):**
- НЕ моделируем весь Норникель или конкретную руду Талнаха.
- НЕ считаем полную периодическую DFT на срезе сульфидной поверхности
  (адсорбция молекула-на-поверхности) — это отдельная, гораздо более
  тяжёлая задача, не про 2-3 недели. Дескрипторы — молекулярные
  (HOMO/LUMO, дипольный момент газовой фазы), не поверхностные.
  Это ограничение стоит явно проговорить в README проекта, а не
  замалчивать — как и в остальном портфолио.
- НЕ утверждаем, что нашли реальный новый реагент — это демонстрация
  методологии на правдоподобном, литературно обоснованном
  синтетическом таргете, а не открытие.
- НЕ гонимся за вторым классом реагентов (дитиофосфаты и т.д.) в MVP —
  опционально, если останется время после основного скоупа.

## 2. Почему именно ксантогенаты — методологическое обоснование

Не произвольный выбор. Из литературы (проверено поиском при составлении
этого плана):

- Собирающая способность растёт с длиной алкильной цепи, но
  селективность падает — классический, хорошо задокументированный
  компромисс (тот же паттерн, что уже был в flotation_reagent_opt, только
  теперь на уровне молекулы, а не дозировки).
- Существует оптимальная длина цепи: длиннее — сильнее адсорбция, но
  хуже растворимость, есть внутренний максимум чистой эффективности.
- Разветвлённые изомеры короче ~C5 эффективнее прямоцепочечных
  аналогов, длиннее — наоборот (нетривиальная, не монотонная
  зависимость — хороший тест для QSPR-модели, не тривиальная линия).
- **Прямой литературный прецедент**: DFT-дескрипторы граничных орбиталей
  (HOMO/LUMO) применялись для предсказания относительной эффективности
  флотации этил-/изобутил-/амил-ксантогената, с ранжированием
  amyl > isobutyl > ethyl по данным исследования (ScienceDirect,
  "Evaluation of flotation collectors for copper sulfides and pyrite,
  III: Effect of xanthate chain length and branching"). Это не хайпотеза
  с нуля — сам подход «DFT descriptors → QSPR» для ЭТОГО класса молекул
  уже валидирован в открытой науке. Использовать как контрольную точку
  (см. неделя 1).

## 3. Технологический стек

| Компонент | Инструмент | Почему |
|---|---|---|
| Генерация кандидатов | RDKit (SMILES → 3D-структура) | стандарт индустрии, открытый |
| DFT-дескрипторы | **Psi4** (не xtb) | настоящий ab initio DFT, а не полуэмпирика — раз в резюме будет написано «DFT», лучше чтобы это было им; open-source, conda-forge, Python-API, активно поддерживается (последний релиз и документация обновлялись в 2026); есть готовые обучающие тетрадки Psi4NumPy для быстрого onboarding |
| QSPR-модель | scikit-learn / statsmodels | линейная регрессия или Random Forest на малом наборе дескрипторов — решить по факту после EDA (см. неделя 2) |
| Дашборд | Streamlit + Plotly | тот же стек, что в остальном портфолио — консистентность |

**Уровень теории DFT по умолчанию:** B3LYP/6-31G* — стандартный, быстрый,
повсеместно используемый для такого размера молекул (~10-20 тяжёлых
атомов) уровень. Не самый точный из возможных — и это нормально
проговорить в README как осознанный компромисс скорость/точность для
MVP, а не как недостаток.

Установка: `conda env create -f environment.yml && conda activate flotation-collectors`
(Psi4 ставится только через conda-forge, pip-пакета нет).

## 4. Архитектура пайплайна

```
SMILES-библиотека кандидатов (RDKit-валидация)
        │
        ├──► RDKit структурные дескрипторы (длина цепи, разветвлённость,
        │     молекулярная масса, LogP и т.д.)
        │
        └──► Psi4 DFT-дескрипторы (геометрия → SCF/DFT → HOMO, LUMO,
              gap, дипольный момент)
                    │
                    ▼
        Объединённая таблица дескрипторов
                    │
                    ▼
        Синтетический литературно-обоснованный таргет
        (recovery-прокси растёт с длиной цепи с насыщением;
         selectivity-прокси падает с длиной цепи и коррелирует
         с HOMO-LUMO gap; см. неделя 2 для точных формул)
                    │
                    ▼
        QSPR-модель (дескрипторы → таргет)
                    │
                    ▼
        Расширенная виртуальная библиотека (больше кандидатов,
        не считавшихся через DFT напрямую)
                    │
                    ▼
        Виртуальный скрининг: ранжирование по предсказанной
        желательности (та же функция Харрингтона, что и в
        flotation_reagent_opt — но теперь это скрининг дискретного
        набора кандидатов, а не непрерывная сетка 50×50×50)
                    │
                    ▼
        Streamlit-дашборд + README + GitHub
```

**Важное методологическое отличие от flotation_reagent_opt**, стоит
явно подчеркнуть в README нового проекта: там желательность искалась
по непрерывной сетке процессных параметров (дозировки), здесь —
это ранжирование ДИСКРЕТНОГО набора молекулярных кандидатов
(virtual screening). Одна и та же философия (Харрингтон), два разных
класса задачи (continuous optimization vs. discrete screening) — это
показывает не копипаст метода, а понимание, когда какой вариант уместен.

## 6. План по неделям

### Неделя 1 — Фундамент: RDKit + первая живая DFT-молекула
- RDKit: провалидировать 15 SMILES из `candidate_library.py`
  (`Chem.MolFromSmiles(s) is not None` на каждую), канонизировать.
- Psi4: установить, пройти 2-3 туториала из Psi4NumPy (geometry
  optimization, SCF energy) — не для проекта, для рук/интуиции.
- Посчитать DFT-дескрипторы для ОДНОЙ простой молекулы (ethyl xanthate)
  вручную, построчно свериться с выводом Psi4 — прежде чем
  автоматизировать на всю библиотеку.
- **Контрольная точка**: посчитать ethyl/isobutyl/amyl xanthate,
  сравнить порядок HOMO (или gap) с литературным ранжированием
  amyl > isobutyl > ethyl (см. раздел 2). Совпало по порядку — двигаться
  дальше уверенно. Не совпало — сначала разобраться, почему, не гнать
  весь пайплайн на потенциально сломанной первой ступени.

### Неделя 2 — Полный пайплайн дескрипторов + синтетический таргет + QSPR
- Батч-расчёт DFT-дескрипторов для всех 15 стартовых структур
  (заложить время — DFT на молекулу может занять минуты, не секунды).
- RDKit структурные дескрипторы (длина цепи уже есть, добавить
  молекулярную массу, LogP, TPSA — стандартный набор).
- Синтетический таргет (два отклика, как в flotation_reagent_opt):
  - Recovery-прокси: растёт с длиной цепи с насыщением (см. литературу,
    раздел 2) + возможная мягкая связь с электронной плотностью/gap.
  - Selectivity-прокси: падает с длиной цепи, отрицательная связь с
    узостью HOMO-LUMO gap (меньше gap → выше реакционная способность →
    менее селективная хемосорбция — стандартная логика теории
    граничных орбиталей, не придуманная связь).
  - Точные коэффициенты — подобрать так, чтобы получить содержательный
    trade-off, как в прошлый раз с flotation_reagent_opt (эмпирически,
    через прогон и проверку разумности диапазонов).
- QSPR-модель: начать с простой линейной/ridge-регрессии (мало точек,
  мало признаков — сложная модель типа RF рискует переобучиться на 15
  примерах), Random Forest — только если после EDA видно выраженную
  нелинейность и данных для неё достаточно.

### Неделя 3 — Расширение библиотеки, скрининг, дашборд, публикация
- Сгенерировать более широкую виртуальную библиотеку (больше длин
  цепи, возможно другие функциональные группы-модификации в пределах
  класса ксантогенатов) — эти НЕ считаются через DFT (дорого), только
  через RDKit-дескрипторы + QSPR-предсказание DFT-дескрипторов, ЛИБО
  явно ограничиться только теми, что реально прогнаны через Psi4,
  если времени в обрез — это тоже нормально и честно.
- Ранжирование по желательности (recovery + selectivity), топ-N
  кандидатов на выходе.
- Streamlit-дашборд: таблица кандидатов, DFT-дескрипторы, QSPR-диагностика
  (R², коэффициенты), ранжированный скрининг.
- README с честной маркировкой статуса (см. раздел 7) — тот же принцип,
  что уже работает во всём остальном портфолио.
- Публикация на GitHub, ссылка — в резюме и профильный README.

## 7. Как описывать в резюме/README (статус-маркировка)

По аналогии со всем остальным портфолио (методология / in silico / production):

> **методология, in silico, молекулярные (не поверхностные) DFT-дескрипторы**

Не «AI спроектировал новый флотационный реагент» — а «продемонстрирована
методология QSPR+DFT для скрининга молекул-кандидатов на литературно
обоснованном синтетическом таргете; перенос на реальные адсорбционные
данные и синтез — следующий этап» — та же честная формула, что уже
применена в Elastomeric 1K PU и EpoxyStructural-EP1.

## 8. Открытые технические решения — на усмотрение (не блокируют старт)

Эти вопросы нормально решить по ходу работы, не нужно решать заранее:
- Точный функционал/базис (B3LYP/6-31G* как стартовая точка — можно
  усложнить, если хватит времени и вычислительных ресурсов).
- Линейная регрессия vs. Random Forest для QSPR — решить после EDA
  недели 2 по фактической форме зависимостей.
- Расширять ли на второй класс реагентов (дитиофосфаты) — опционально,
  только если недели 1-2 прошли быстрее плана.
