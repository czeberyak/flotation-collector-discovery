# 🧬 Flotation Collector Discovery Pipeline

**Статус: методология, in silico — молекулярные (не поверхностные) DFT-дескрипторы.**
Виртуальный скрининг молекул-собирателей для сульфидной флотации через
связку RDKit + DFT (Psi4) + QSPR, на литературно обоснованном
синтетическом таргете. См. [`PLAN.md`](./PLAN.md) для полного плана и
методологического обоснования.

## Зачем этот проект

Продолжение методологии [`elastomeric_1k_pu`](https://github.com/czeberyak/elastomeric_1k_pu)
и [`flotation_reagent_opt`](https://github.com/czeberyak/flotation_reagent_opt)
(DoE/RSM/desirability), теперь на уровне **молекулярного дизайна**, а не
оптимизации рецептуры/режима на фиксированной химии. Закрывает
вычислительный трек (QSPR/QSAR + DFT), упоминаемый как следующий шаг во
всём остальном портфолио, но нигде ранее не реализованный даже как
методология.

## Класс молекул: алкилксантогенаты

Не произвольный выбор — самый распространённый и наиболее изученный в
литературе класс собирателей для сульфидной флотации, с
задокументированной структурно-функциональной зависимостью (длина
цепи, разветвлённость) и прямым литературным прецедентом использования
DFT-дескрипторов граничных орбиталей для предсказания относительной
эффективности флотации. Подробности и источники — в `PLAN.md`, раздел 2.

## Что это НЕ

- Не полная периодическая DFT адсорбции молекулы на срезе сульфидной
  поверхности (это отдельная, значительно более тяжёлая задача).
- Не утверждение об открытии нового реального реагента — демонстрация
  методологии на правдоподобном синтетическом таргете.
- Не production-инструмент — учебный/демонстрационный MVP по плану
  на 2–3 недели.

## Стек

RDKit (молекулярные дескрипторы) · Psi4 (DFT, B3LYP/6-31G*) ·
scikit-learn/statsmodels (QSPR) · Streamlit + Plotly (дашборд)
